### “列表失败”的证据边界

- 记录 `method=http,http_links=0,pw_links=0` 不代表完全没有尝试浏览器：当前函数在浏览器未获得更多链接时会返回 http。
- 新疆日报/天山网共享 `ts.cn` 入口；部分尝试出现连接中断，也有渲染后 0 链接。主表归列表失败，网络症状作为次要证据，不能把一个媒体的重试误算成多个源。
- 大连新闻传媒集团还出现 `Page.content: Unable to retrieve content because the page is navigating`，属于浏览器取内容时机问题；不能简单认为未启用浏览器。
- 常德广播电视台先有 HTTP 证书错误，随后浏览器完成但仍 0 链接，因此按最终列表未产出归类。
- 广西广播电视台的“无效文章”根源是候选中混入许可证页，不是放宽标题/正文字数就能解决。
